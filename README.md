🏥 Smart Health Assistant

A Flask-based healthcare assistance web application built using Python.

📌 About the Project

Smart Health Assistant is a web-based application that helps users enter their symptoms and receive preliminary health guidance.

It provides a simple interface for symptom assessment, patient information, health history, and doctor appointment management.
✨ Features

- Symptom-based health assessment
- Patient information input
- Preliminary health guidance
- Risk level indication
- Emergency warning messages
- Assessment history management
- Patient dashboard
- Doctor appointment system
- User-friendly interface
- 🛠️ Technologies Used

Frontend

- HTML5 – For webpage structure.
- CSS3 – For styling and responsive design.
- JavaScript – For interactive elements.

Backend

- Python – Main programming language.
- Flask – Web application framework.
- Jinja2 – For dynamic HTML templates.

Development Tools

- Visual Studio Code
- Git
- GitHub
- Python Virtual Environment

⚙️ Installation and Setup

Follow these steps to run the project locally.

Step 1: Clone the Repository

git clone https://github.com/26kadir/Smart-Health-Assistant-.git

Step 2: Open the Project Folder

cd Smart-Health-Assistant-

Step 3: Create a Virtual Environment

python -m venv venv

Step 4: Activate the Virtual Environment

For Windows PowerShell:

venv\Scripts\Activate.ps1

Step 5: Install Flask

pip install flask

Step 6: Run the Application

python app.py

Step 7: Open in Browser

Visit the following address:

http://127.0.0.1:5000/

The Smart Health Assistant application will open in your browser.

🎯 Project Objective

The main objective of Smart Health Assistant is to provide users with an easy-to-use healthcare assistance platform.

It aims to:

- Make preliminary symptom assessment accessible.
- Provide basic health-related information.
- Highlight symptoms that may require urgent medical attention.
- Maintain a history of previous assessments.
- Provide access to a doctor appointment interface.

🔄 Application Workflow

The Smart Health Assistant follows a simple workflow:

1. User opens the application.
2. User enters basic patient information.
3. User selects symptoms and provides additional details.
4. The application processes the submitted information.
5. A preliminary health assessment is generated.
6. The user can review the assessment and health guidance.
7. Assessment details can be viewed in the history section.
8. Users can explore the dashboard and doctor appointment features.

---

📊 Main Application Modules

1. Home Page

Provides an interface for entering patient details and selecting symptoms.

2. Symptom Assessment

Processes the submitted information and displays preliminary health guidance.

3. Assessment History

Allows users to view previously generated assessment records.

4. Dashboard

Provides an overview of available healthcare application features.

5. Doctor Appointment

Provides an interface for submitting doctor appointment requests.
